# Security Policy

## Supported Versions

Only the latest version of this list is supported.

## Reporting a Vulnerability

If you find a security issue (e.g., a malicious link, sensitive data exposure in a linked project, or a security flaw in the repository structure), please report it by opening an issue or contacting the maintainer directly.

Note: This repository is a curated list of external resources. We do not control the security of the linked projects. Always perform your own due diligence when using third-party software, especially for financial data.
